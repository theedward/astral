# Astral Clock

A standalone digital clock for Retail and Forever, with no WeakAuras dependency.
Defaults to local computer time in 24-hour format, 44px text, top centre.
Its position and preferences persist per WoW account.

- `/aclock unlock` — drag with the left mouse button.
- `/aclock lock` — lock and allow clicks through the clock.
- `/aclock size 54` — set text size (18–100).
- `/aclock server` or `/aclock local` — choose time source.
- `/aclock hide`, `/aclock show`, `/aclock reset`.
